Политика конфиденциальности

Приложение anekdotiki. Действует с 28 октября 2026 года.

Что это за приложение

anekdotiki — личный инструмент владельца. Он загружает подготовленные видеоролики на YouTube-канал владельца через YouTube Data API.

Какие данные используются

  • Доступ к YouTube-каналу владельца, который он сам выдал через вход в аккаунт Google. Нужен только для загрузки видео на этот канал.
  • Данные видео: файл, заголовок, описание, теги.

Как данные хранятся и передаются

Токены доступа хранятся только на компьютере владельца, в его собственной установке n8n. Они не передаются третьим лицам, не продаются и не используются для рекламы. Приложение не собирает данные других пользователей.

Использование данных Google

Использование и передача информации, полученной из API Google, соответствуют Политике в отношении пользовательских данных в сервисах API Google, включая требования об ограниченном использовании.

Отзыв доступа

Доступ можно отозвать в любой момент на странице myaccount.google.com/permissions. После этого приложение перестанет работать с каналом.
